# Tonal EQ

Chrome 分頁音效等化器（Manifest V3）。對任何分頁的聲音即時套用 11 段參數式 EQ 與音效，介面依瀏覽器語言自動顯示繁體中文或英文。

## 功能

- **11 段參數式 EQ**：低架 ×1、峰值 ×9、高架 ×1，直接在曲線圖上拖曳
  - 拖曳圓點：調整頻率與增益
  - `Shift` + 拖曳，或滑鼠滾輪：調整 Q（頻寬）
  - 雙擊圓點或按 `Delete`：重設該頻段
  - 選取後方向鍵微調（`Shift` 加大幅度）
- **即時頻譜**：顯示處理後的聲音
- **效果**：聲道處理（原聲／去人聲／中央聲道）、失真、殘響、防爆音限制器
- **內建效果預設集**：原聲、重低音加強、超低音、電影院外、廁所回音、山洞回音、破音低音、電話聲
- **自訂預設集**：儲存、刪除、匯入／匯出 JSON
- **多分頁**：可同時對多個分頁啟用，共用同一組 EQ
- **主音量**：-30 ～ +20 dB

## 安裝（開發者模式）

1. 開啟 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選擇本專案資料夾（含 `manifest.json` 的那層）
4. 建議將擴充功能釘選到工具列

需求：Chrome 116 以上。

## 使用方式

1. 在要處理的分頁點擊工具列圖示
2. 按「啟用此分頁」，圖示會出現 `EQ` 徽章
3. 調整 EQ 或套用預設集；設定會自動保存
4. 要停止時再按一次按鈕，或到「播放中分頁」頁籤停止

## 架構

```
popup（介面）──設定──▶ background（service worker：生命週期、儲存、徽章）
   │                         │
   │  tabCapture.getMediaStreamId
   │                         ▼
   └──即時參數 / 頻譜 Port──▶ offscreen document（Web Audio 音訊引擎）
```

訊號流程：

```
分頁音訊 → 聲道處理 → 11 段 EQ → 失真 → 殘響 → 主音量 → 限制器 → 輸出
                                                        └→ 頻譜分析
```

MV3 的 service worker 不能使用 Web Audio，所以音訊處理放在 offscreen document 中執行。沒有任何分頁啟用時，offscreen document 會自動關閉以釋放資源。

| 檔案 | 說明 |
|---|---|
| `manifest.json` | 擴充功能設定 |
| `src/background.js` | Service worker |
| `src/offscreen.js` | 音訊引擎 |
| `src/popup.*` | 介面 |
| `src/shared/config.js` | 頻段定義、範圍、預設值 |
| `src/shared/presets.js` | 內建預設集、匯入匯出 |
| `src/shared/i18n.js` | 介面翻譯（繁中／英文） |
| `_locales/` | 擴充功能名稱與說明的翻譯 |

## 已知限制

- `chrome://` 頁面、擴充功能商店等瀏覽器內建頁面無法擷取音訊
- 同一分頁無法同時被兩個擷取工具使用（例如其他 EQ 或錄影擴充功能）
- 效果面板中的「去人聲」與「中央聲道」是利用左右聲道相減／相加的近似做法，效果取決於歌曲混音；真正的人聲分離需要 AI 模型，無法在瀏覽器中即時執行
- 分頁擷取會經過額外的音訊緩衝，可能有些微延遲

## 匯入格式

匯出檔格式：

```json
{
  "format": "tonal-eq-presets",
  "version": 1,
  "presets": {
    "名稱": { "bands": [{ "f": 20, "g": 0, "q": 0.7071 }], "stereo": "normal", "distortion": {}, "reverb": {} }
  }
}
```

匯入時也接受 `{ "名稱": { "frequencies": [...], "gains": [...], "qs": [...] } }` 這種三個平行陣列的通用格式。
